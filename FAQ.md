# IELTS Vocab App — FAQ

_Last Updated: 2025-10-27_

Welcome to the IELTS Vocab App support FAQ. Below are answers to common questions to help you get started and troubleshoot.

## Getting Started

### What is IELTS Vocab?
IELTS Vocab helps learners prepare for the IELTS exam by mastering high-frequency vocabulary through curated word lists, smart practice, and spaced repetition.

### Which devices are supported?
The app supports modern iOS devices (iPhone and iPad). Performance and layout adapt to different screen sizes.

---

## Features & Content

### How is the vocabulary organized?
- **Word Lists**: Grouped by topics (Education, Environment, Technology, etc.)
- **Levels**: Foundation → Intermediate → Advanced
- **Practice Modes**: Flashcards, fill-in-the-blank, multiple choice, and review sessions

### What practice features are available?
- Spaced repetition to reinforce memory
- Example sentences from academic contexts
- Pronunciation helpers (where available)

## Accounts & Data

### Do I need to create an account?
No account is required to use core features. Optional sign-in (if enabled) can sync progress across devices.

We keep data minimal. See the **Privacy Policy** for details. No sensitive personal information is required for core usage.

## Troubleshooting

### The app is not syncing.
- Check your internet connection
- Ensure you’re signed in (if using sync)
- Try restarting the app

### Audio or examples aren’t loading.
- Verify connectivity
- Re-download the word pack
- Update to the latest app version
